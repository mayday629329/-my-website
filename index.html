🧾 退稅與機場報到

12/6 約 16:00 抵達仁川 T1 3F 出境大廳。長榮通常在起飛前約 2.5 小時（約 17:15）開櫃，距 19:45 起飛還有約 3 小時 45 分，時間很充裕。順序：刷退稅單 → 看 O 或 X → 託運 → 看 X 光 → 安檢 → 領退稅現金。

1. 找長榮櫃檯

到 3F 出境大廳，看中央大螢幕核對航班 BR159，通常在 J 或 K 櫃檯一帶。

2. 先刷退稅單（管制區外，託運之前）

退稅機在 3F D、E 櫃檯後方與 J、K 櫃檯後方，就在長榮櫃檯正後方。機台有中文介面：先放護照掃描，再逐張掃描退稅單條碼。
顯示 O：通過，直接去託運。
顯示 X：單筆退稅金額超過 ₩75,000 或被抽查，要把行李推到旁邊的海關申報處，給海關檢查商品並蓋章後才能託運，所以退稅商品先放在容易取出的地方。
在 Olive Young、Dior 等店已經現場扣除退稅金額的單據，不用再刷。退稅門檻是單筆滿 ₩15,000。

3. 報到拿登機證

做法 A（最推薦）：起飛前 48 小時內用長榮 App 或官網線上報到，到機場走自助託運（Bag Drop）專用通道，人比較少。
做法 B：排人工櫃檯，把護照交給地勤人員辦理。

4. 託運行李

行李放上秤重，長榮會檢查是否符合機票限重（例如 23 公斤）。地勤會貼上行李條，並給你行李收據（通常貼在登機證背面），要收好。走自助櫃檯則自己掃描登機證、自己貼行李條，機器會自動送走行李。

5. 確認行李通過 X 光

行李送走後不要立刻離開，走到櫃檯區後方的行李 X 光螢幕前等 3–5 分鐘，確認行李順利通過、沒有被海關攔下。行動電源和打火機不能放託運行李。確認後報到託運才算完成。

6. 進管制區

排隊過安全檢查與證照查驗。

7. 領退稅現金（管制區內）

在 3F 免稅店區 28 號登機門（Gate 28）附近的退稅專區。自動退稅機可選擇退成韓元現金，現場也有人工櫃檯（07:00–22:00），不放心可以把護照交給服務人員核銷領現金。

海關申報處管退稅商品，櫃檯後方的 X 光螢幕管行李箱裡有沒有違禁品，兩件事是分開的。
